Khôi Phục từ File Sao Lưu

Chọn file sao lưu JSON trước đó để nạp lại toàn bộ dữ liệu hệ thống. Thao tác này sẽ cập nhật lại dữ liệu phòng, hợp đồng và hóa đơn tương ứng trong file.
